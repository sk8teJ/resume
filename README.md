# Резюме — Ярослав Прокошкин

Одностраничный сайт-резюме. Для сохранения в PDF откройте сайт и нажмите **«Скачать PDF»**, затем выберите в диалоге печати браузера **«Сохранить как PDF»**.

## Публикация через GitHub Pages

1. Откройте репозиторий **Settings → Pages**.
2. В разделе **Build and deployment** выберите **Deploy from a branch**.
3. Выберите ветку **main** и папку **/(root)**, затем нажмите **Save**.
4. Через некоторое время сайт будет доступен по адресу: https://sk8tej.github.io/resume/

Для локального просмотра достаточно открыть `index.html` в браузере.
